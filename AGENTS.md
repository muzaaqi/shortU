## 1. Project Overview

A full-stack URL shortener and QR code generator. Users shorten URLs into 7-character slugs, get a QR code from the short URL, and can optionally enable an interstitial ad page per link. Built as a monorepo fullstack app — no separate backend.

**Core rule:** All database access happens inside server functions. Nothing touches the DB from the client side.

## 4. Database Schema

Defined in `src/server/db/schema.ts`. This is the canonical schema — always keep it in sync with migrations.

```ts
// users — managed by Better Auth, do not mutate manually
export const users = pgTable("users", {
  id: text("id").primaryKey(),
  name: text("name").notNull(),
  email: text("email").notNull().unique(),
  emailVerified: boolean("email_verified").notNull(),
  image: text("image"),
  createdAt: timestamp("created_at").notNull(),
  updatedAt: timestamp("updated_at").notNull(),
});

// sessions, accounts, verifications — also managed by Better Auth
// see auth-server.ts for full Better Auth schema

// links — core domain table
export const links = pgTable("links", {
  id: text("id").primaryKey(),                          // nanoid()
  userId: text("user_id").references(() => users.id),  // null = anonymous
  slug: text("slug").notNull().unique(),
  originalUrl: text("original_url").notNull(),
  qrCode: text("qr_code"),                             // base64 data URL, set at creation
  adEnabled: boolean("ad_enabled").notNull().default(false),
  clickCount: integer("click_count").notNull().default(0),
  createdAt: timestamp("created_at").notNull(),
  updatedAt: timestamp("updated_at").notNull(),
});

// clicks — lightweight analytics
export const clicks = pgTable("clicks", {
  id: text("id").primaryKey(),
  linkId: text("link_id").references(() => links.id, { onDelete: "cascade" }),
  clickedAt: timestamp("clicked_at").notNull(),
  userAgent: text("user_agent"),
});
```

## 5. Server Functions

All server functions live in `src/server/functions/`. They are called from the client using TanStack Query.

**Pattern:**
```ts
// server/functions/links.ts
import { createServerFn } from "@tanstack/start";

export const createLink = createServerFn({ method: "POST" })
  .validator((data: CreateLinkInput) => data)
  .handler(async ({ data, context }) => {
    // DB access here — never on the client
  });
```

**Available server functions:**

| Function | File | Description |
|---|---|---|
| `createLink` | links.ts | Creates a new link — generates slug (or validates custom), creates QR, inserts to DB |
| `getLinks` | links.ts | Returns paginated list of the current user's links |
| `getLinkBySlug` | links.ts | Looks up a link by slug — used in $slug.tsx and go.$slug.tsx loaders |
| `deleteLink` | links.ts | Deletes a link owned by the current user |
| `toggleAdMode` | links.ts | Flips `adEnabled` boolean for a link |
| `trackClick` | analytics.ts | Inserts a click event (fire-and-forget, called from redirect/go routes) |
| `getLinkStats` | analytics.ts | Returns click count for a link |
| `getSession` | auth.ts | Wraps Better Auth session check for use in loaders |

## 6. Routing & Redirect Logic

### Route: `/` (index.tsx)
Landing page. Contains `<LinkForm />`. Unauthenticated users can use it; their link is not persisted to an account.

### Route: `/dashboard` (dashboard.tsx)
Auth-protected. Loads user's links via `getLinks`. Renders `<LinkCard />` list.

### Route: `/$slug` ($slug.tsx)
The hot path. Loader calls `getLinkBySlug`. Branches:
- `adEnabled === false` → `throw redirect({ href: link.originalUrl, statusCode: 301 })`
- `adEnabled === true` → `throw redirect({ to: "/go/$slug" })`

Keep this loader as lean as possible. No unnecessary awaits.

### Route: `/go/$slug` (go.$slug.tsx)
Interstitial page. Loader calls `getLinkBySlug`. Renders destination URL, ad slot placeholder, and "Continue" button. On button click, navigates to `link.originalUrl`.

### Route: `/api/auth/$` (api/auth/$.ts)
Better Auth catch-all. Do not modify — it's generated by Better Auth setup.

## 7. Auth

Managed by Better Auth. Config lives in two files:

- `src/lib/auth-server.ts` — server config: OAuth providers (Google, GitHub), Drizzle adapter pointing to Neon, session options.
- `src/lib/auth.ts` — client config: `createAuthClient()` with the app's base URL.

**Rules:**
- Never expose DB credentials on the client side.
- Use `getSession` server function in route loaders to get the current user.
- Protect `/dashboard` by checking session in the loader and redirecting to `/` if unauthenticated.

## 8. QR Code Generation

Handled in `src/lib/qr.ts`:

```ts
import QRCode from "qrcode";

// Returns a base64 PNG data URL
export async function generateQR(url: string): Promise<string> {
  return QRCode.toDataURL(url, {
    width: 300,
    margin: 2,
    color: { dark: "#000000", light: "#ffffff" },
  });
}
```

- Always called server-side inside `createLink`.
- The `qrCode` column stores the base64 string directly.
- To render: `<img src={link.qrCode} />`
- To download: create a temporary anchor with `download="qr.png"` and `href={link.qrCode}`.

## 9. Slug Generation & Validation

In `src/lib/slugify.ts`:

```ts
import { nanoid } from "nanoid";

export const generateSlug = () => nanoid(7);

// Only alphanumeric and hyphens, 3–50 chars
export const SLUG_REGEX = /^[a-z0-9-]{3,50}$/;

// Reserved slugs — cannot be used as custom slugs
export const RESERVED_SLUGS = ["api", "dashboard", "go", "auth", "admin", "login", "logout"];

export function validateSlug(slug: string): { valid: boolean; reason?: string } {
  if (!SLUG_REGEX.test(slug)) return { valid: false, reason: "Slug must be 3–50 lowercase alphanumeric characters or hyphens." };
  if (RESERVED_SLUGS.includes(slug)) return { valid: false, reason: "This slug is reserved." };
  return { valid: true };
}
```

## 10. UI Rules

> These rules are enforced without exception. Read before touching any component.

### Base UI — NOT Radix UI
This project uses shadcn with **Base UI** as the primitive layer.

```ts
// CORRECT
import { Button } from "~/components/ui/button";

// WRONG — will cause a runtime error
import { Dialog } from "@radix-ui/react-dialog";
```

### Modify at the source
All component customization happens inside `components/ui/*.tsx`. Do not override styles at the usage site.

```ts
// CORRECT — edit the component
// components/ui/button.tsx
const buttonVariants = cva("...", { variants: { ... } });

// WRONG — override at usage
<Button className="bg-red-500 override-everything" />
```

### Read DESIGN.md before touching UI
Every component must use tokens from DESIGN.md. No hardcoded colors, spacing, or font sizes.

### Reusability checklist (before creating a new component)

3. If new component is needed: use `memo()`, `useMemo()`, `useCallback()`, `Suspense`, `ErrorBoundary`, `lazy()` where appropriate.
4. Always accept `className` prop and merge with `cn()`.

### Read documentation via Context7 MCP
Before using any library API (TanStack Router, TanStack Start server functions, Drizzle, Better Auth, shadcn) — fetch the current docs via Context7 MCP. Do not assume from training data.

## 11. TanStack Query Conventions

- All server function calls are wrapped in `useQuery` or `useMutation`.
- Query keys are defined as constants in the same file as the query:

```ts
export const LINK_KEYS = {
  all: ["links"] as const,
  list: () => [...LINK_KEYS.all, "list"] as const,
  detail: (slug: string) => [...LINK_KEYS.all, "detail", slug] as const,
};
```

- Mutations invalidate the relevant query key on success:

```ts
const { mutate } = useMutation({
  mutationFn: toggleAdMode,
  onSuccess: () => queryClient.invalidateQueries({ queryKey: LINK_KEYS.list() }),
});
```

- Use optimistic updates for `toggleAdMode` and `deleteLink` — these are frequent dashboard interactions.

## 14. Code Conventions

### Comments
Every function and non-trivial block must have a comment explaining:
1. What it does
2. How it works (if non-obvious)
3. Where it's imported from / used

```ts
/**
 * Creates a new shortened link.
 * Validates or generates a slug, generates a QR code from the short URL,
 * and inserts the record into the links table.
 * Used by: src/routes/index.tsx → LinkForm submit handler
 */
export const createLink = createServerFn({ method: "POST" })
  ...
```

### Naming
- Files: `kebab-case.tsx`
- Components: `PascalCase`
- Server functions: `camelCase` (verb + noun: `createLink`, `toggleAdMode`)
- Query keys: `SCREAMING_SNAKE_CASE` constant objects
- DB columns: `snake_case` in schema, `camelCase` in TypeScript via Drizzle mapping

### Imports
Always use the `~/` alias for project imports:
```ts
import { db } from "~/server/db";
import { generateQR } from "~/lib/qr";
```

### No client-side secrets
```ts
// WRONG — never in a component or client module
const db = drizzle(process.env.DATABASE_URL);

// CORRECT — only inside server functions
export const getLinks = createServerFn(...).handler(async () => {
  return db.select().from(links); // db imported from src/server/db/index.ts
});
```
